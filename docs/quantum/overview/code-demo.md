## 在讲什么

同一张「0/1 各一半」的直方图，可以来自**相干叠加** $|+\rangle$，也可以来自**完全混合** $I/2$。再插一个 Hadamard：只有叠加会被「收回」到 $|0\rangle$。这是五条专题共用的第一课。
