# 控制论：误差如何变成力

> [!WARNING]
> 🧪 Beta公测版本提示：教程主体已完成，正在优化细节，欢迎大家提Issue反馈问题或建议。

> 侧栏里的 **控制论** 不是两篇长文，而是一组课：**导论** 先画闭环；**经典控制** 用传递函数、PID、根轨迹、频域说话；**现代控制** 用状态、LQR、卡尔曼、李雅普诺夫说话。点分组标题可进本页或分组首页。几何接到 [机器人学](/robotics/)；在想象里滚动未来见 [世界模型](/world-models/intro/)。

> **图解说明**：左列经典（$G(s)$、PID、根轨迹、Bode）；中列现代（$Ax+Bu$、LQR、卡尔曼、Lyapunov）；右列虚线是数字控制、MPC、自适应等，本笔记先不展开。底栏接到机器人学与世界模型。

| 入口 | 在问什么 |
|------|----------|
| **[控制论导论](/control/overview/)** | 开环 vs 闭环；极点如何决定阶跃长什么样 |
| **[经典控制](/control/classical/)** | 传递函数、PID、根轨迹、频域裕度 |
| **[现代控制](/control/modern/)** | 状态空间、LQR、观测器、非线性稳定 |

开环是「算好输入，闭眼执行」。闭环把输出送回来，误差 $e=r-y$ 才有机会被消掉。后面每一章都是在给这张回路配不同的语言。
