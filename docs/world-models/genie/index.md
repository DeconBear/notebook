# Genie：从视频中长出可玩的世界

> [!WARNING]
> 🧪 Beta公测版本提示：教程主体已完成，正在优化细节，欢迎大家提Issue反馈问题或建议。

## 1. 交互式世界模型

Genie（Google DeepMind）试图从大规模视频中学习：**潜动作接口 + 下一帧/下一状态生成**，使智能体（或人类）能用动作「玩」生成的环境。

关键要素：

- **潜动作**：不一定等于键盘语义，而是从数据中发现的可控因素
- **动态模型**：条件于动作的未来生成
- **可玩性**：强调交互闭环，而非一次性视频生成

![Genie 概念](./images/wm06-01-genie.png)

> **图解说明**：从视频里发现潜动作，再以动作为条件生成下一帧世界——重点是「可玩的交互闭环」，而不只是一次性好看的视频。

## 2. 版本直觉

Genie-1 → 2 → 3：从 2D 可控世界走向更高分辨率、更长时一致性的实时交互。

## 3. 与 Sora/Cosmos

Genie 更强调**动作条件与交互**；视频基础模型更强调开放生成。二者互补。
