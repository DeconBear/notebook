# 视频生成式世界模型：从 Sora 到 Cosmos

> [!WARNING]
> 🧪 Beta公测版本提示：教程主体已完成，正在优化细节，欢迎大家提Issue反馈问题或建议。

## 1. 新范式：用生成模型当「世界模拟器」

当视频生成模型能够保持物体一致性、大致遵守物理、并接受文本/动作条件时，人们开始把它当作**世界模型**：在生成的未来里做想象、规划或训练。

代表方向：

- **Sora 类**：大规模视频扩散 / DiT，强调长期一致性与场景复杂度
- **NVIDIA Cosmos**：面向具身与物理 AI 的世界基础模型族（自回归 / 扩散变体）

![视频世界模型概览](./images/wm07-01-video-wm.png)

> **图解说明**：Sora/Cosmos 一类模型在像素或视频潜空间做大规模未来预测，视觉细节强、开放语义好；物理真实性与精细动作可控性仍是开放问题——与 Dreamer（紧凑控制潜空间）和 Genie（显式交互动作）形成互补。

## 2. 能力与局限

| 能力 | 局限 |
|------|------|
| 丰富视觉细节 | 物理仍可被「看起来像」欺骗 |
| 开放世界语义 | 可操控性 / 动作接口仍在演进 |
| 可缩放数据 | 训练与推理成本极高 |

与 Dreamer/JEPA 不同：它往往**直接在像素/潜视频空间生成**，而不是只为控制服务的紧凑潜动力学。

## 3. 与 Genie 的关系

Genie 强调**可交互的潜动作**；Sora/Cosmos 更偏「被动或弱可控的视频未来」。二者正在合流：更强控制信号 + 更强物理先验。
